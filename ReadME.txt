Setup:

1. Place all Python files and CSV files in the same folder.
2. Open 'main.py' and run the desired inqueries.
3. Run 'demo_milestone3.py' to see: 

- HashMap and Rehashing
- Prerequisite checks during enrollment
- Merge and Quick Sort 
- Waitlist, Binary Search, and Undo feature.

Running the Tests:

1. Make sure `test_milestone3.py` is in the same folder as the other files.
2. Open 'test_milestone3.py' and run the test file.
