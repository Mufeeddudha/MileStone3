Setup:

1. Place all Python files and CSV files in the same folder.
2. Open 'main.py' and run the desired inqueries.
3. Run 'demo_milestone2.py' to see enrollment system, waitlist, sorting, binary search drop, and undo features.


Running the Tests:

1. Make sure `test_milestone2.py` is in the same folder as the other files.
2. Open 'test_milestone2.py' and run the test file.
